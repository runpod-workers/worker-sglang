# SGLang v0.5.15.post1 Worker Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the RunPod worker to the pinned SGLang v0.5.15.post1 CUDA 13 runtime and expose only current server arguments while preserving its request APIs.

**Architecture:** Keep the official worker layout and launch SGLang as a child process. Centralize environment-to-CLI translation in a testable command builder, pin both Docker base variants, and keep HTTP forwarding separate from engine configuration.

**Tech Stack:** Python 3, `unittest`, aiohttp, RunPod Python SDK, Docker Buildx/Bake, SGLang v0.5.15.post1.

## Global Constraints

- Pin SGLang exactly to `v0.5.15.post1`; do not use floating `latest` tags.
- Target CUDA 13.0 on NVIDIA H100 and H200.
- Preserve RunPod native and OpenAI-compatible request formats.
- Preserve stable official-worker environment names, but emit current canonical SGLang CLI flags.
- Remove deprecated NSA, aggregate CUDA Graph, FlashInfer MLA, and overlap-enable mappings.
- Do not add shell-based free-form argument parsing.

- [ ] **Step 2: Run response tests and verify the helper is missing**

Run: `python3 -m unittest tests.test_utils -v`

Expected: import failure for `async_process_response`.

- [ ] **Step 3: Implement and use the shared response helper**

Add this behavior to `utils.py`:

```python
async def async_process_response(response, is_stream, route):
    if not 200 <= response.status < 300:
        yield {
            "error": f"Request to {route} failed with status {response.status}",
            "details": await response.text(),
        }
        return
    if is_stream:
        async for chunk in async_process_stream(response):
            yield chunk
        return
    async for raw_line in response.content:
        line = raw_line.decode("utf-8").strip()
        if line:
            yield line
```

Replace the three duplicated OpenAI POST response loops in `handler.py` with this helper. Keep GET handling and native `/generate` behavior unchanged.
